The Product

One platform, four jobs

Instead of locking analysis into one venue, one body position, or one sport, KineticSense combines hardware, real-time feedback, and a coach workflow in a single institution-ready system.

01

Universal sensor

A single detachable 9-DOF IMU magnetically snaps onto six textile accessories — arm, wrist, shoulder, knee, ankle, and compression shirt. One device, every sport.

02

Real-time scoring

BLE 5.0 streaming with a Madgwick orientation filter delivers drift-free joint angles and a live technique score in under 50 ms — feedback while the athlete is still training.

03

Coach dashboard

Session reports, athlete trends, risk flags, and a rep-by-rep annotation table — the operational home base for the whole team.

Technology

Three-stage AI pipeline

Each stage adds intelligence — delivering value from day one, with no massive labeled dataset required to start.

A

Rule-based scoring

Threshold logic on filtered joint angles. Immediate per-rep score 0–100, no training data needed.

B

1D-CNN classifier

Trained on coach-annotated pilot data for form-quality detection. Validated at Cohen’s κ ≥ 0.65.

C

Per-athlete autoencoder

Builds a personal motion baseline and detects deviation from the athlete’s own profile — it gets sharper the longer it’s used.

THE MOAT →

Coach annotation loop: coaches label reps → labels retrain the model → a proprietary dataset grows with every session. Competitors can copy the hardware. They can’t copy the data.
